El Pollo Loco

El Pollo Loco is a browser-based jump-and-run game inspired by classic platform games. Players collect coins and bottles, defeat enemies, and complete levels until reaching the final boss.

The project focuses on object-oriented programming, responsive design, collision detection, animations, audio management, and mobile touch controls.
